# ECHO Native

**Лаунчер русской локализации Wuthering Waves для Linux.**

ECHO Native помогает установить, обновить и восстановить текстовый перевод Wuthering Waves в Steam-версии игры. Приложение объединяет управление переводами и запуск игры в одном интерфейсе.

## Возможности

- Выбор локализации: **OVERLINK**, **Aniwie** и **qwikki**.
- Загрузка и установка совместимых переводов с проверкой целостности файлов.
- Проверка версии игры и доступности обновлений перевода.
- Автоматическое обнаружение установки Wuthering Waves в Steam.
- Запуск игры через Steam и управление геймпадом.
- Включение лимита 120 FPS и возврат прежнего значения в настройках.
- Проверка простой обёртки из параметров запуска Steam, когда активный аккаунт можно определить однозначно.
- Проверка манифеста при запуске и каждые 30 минут; новые совместимые пакеты загружаются в кеш и проверяются по XXH64.
- Резервное копирование, проверка и восстановление файлов подключения перевода.

## Установка

В [релизе 0.3.5](https://github.com/bromhobit/LInux-rusian-WUWA-launcher/releases/tag/v0.3.5-2) доступны пакеты для **Linux x86-64**:

- **AppImage** — для разных дистрибутивов, включая SteamOS. Скачайте файл, разрешите его выполнение и запустите:
  ```bash
  chmod +x ECHO-Native-0.3.5-x86_64.AppImage
  ./ECHO-Native-0.3.5-x86_64.AppImage
  ```
  Для обычного запуска AppImage нужна поддержка FUSE; если её нет, можно запустить с `APPIMAGE_EXTRACT_AND_RUN=1`.
- **DEB** — для Debian/Ubuntu: скачайте `echo-native_0.3.5-2_amd64.deb` и установите через менеджер пакетов либо командой `sudo apt install ./echo-native_0.3.5-2_amd64.deb`. Пакет содержит AppImage и запускает его с извлечением.

Для **Arch Linux и CachyOS** скачайте [`echo-native-0.3.5-2-x86_64.pkg.tar.zst`](https://github.com/bromhobit/LInux-rusian-WUWA-launcher/releases/download/v0.3.5-2/echo-native-0.3.5-2-x86_64.pkg.tar.zst) и установите командой:

```bash
sudo pacman -U ./echo-native-0.3.5-2-x86_64.pkg.tar.zst
```

При переходе с прежней установки в `~/.local/share/echo-native/bin` пакет сохраняет старый исполняемый файл и перенаправляет существующие ярлыки Steam на версию из `pacman`. При удалении пакета прежний файл восстанавливается.

На стандартной SteamOS системный раздел защищён от записи; для неё удобнее AppImage. Пакеты 0.3.5 прошли автоматические проверки; работа со всеми дистрибутивами и реальной игрой ещё не проверена.

## 120 FPS

В разделе **Настройки → 120 FPS** закройте игру и её лаунчер, затем нажмите **Включить 120 FPS**. Фактическая частота зависит от оборудования и настроек графики. Если игра показывает низкий FPS, проверьте вертикальную синхронизацию и качество графики. При отсутствии необходимых записей ECHO ищет их в базе родительского клиента; если она недоступна, изменение не выполняется.

## Проверка файлов перевода

ECHO ищет Steam-приложение по AppID 3513350 во всех библиотеках Steam, затем определяет папку с клиентом и ресурсами внутри установки. Если найдено несколько подходящих клиентов или несколько версий ресурсов без подтверждения активной версии, установка не выполняется до выяснения пути. Для подключения текста используется штатный `MountResource.txt`, при его отсутствии — `MountLang_en.txt`. Языковые файлы озвучки не заменяются.

Если после обновления игры файл перевода отсутствует, ECHO может предложить установить его повторно. Лаунчер проверяет журнал и таблицу Mount, сохраняет резервную копию журнала и не перезаписывает изменённый или неизвестный файл. Совпадение основной версии и минорной версии игры с переводом не гарантирует совместимость с конкретным микропатчем.

При обнаружении нового совместимого пакета выбранного канала ECHO загружает его в кеш; изменение игровых файлов выполняется после подтверждения установки. При недоступности сети текущие файлы сохраняются. Если обновление игры изменит структуру ресурсов или формат манифеста, может потребоваться обновление ECHO.

## Рекомендуемый Proton и запуск через Steam

Для корректной работы официального лаунчера Wuthering Waves в Linux рекомендуется использовать **[DWProton](https://github.com/dawn-winery/dwproton-mirror/releases)** — в нём содержится исправление (фикс) специально для лаунчера WuWa.

### Экспериментальный прямой запуск через Steam

Откройте в ECHO **Настройки → Прямой запуск через Steam**. Приложение предложит последние сохранённые параметры активного аккаунта. Сверьте их с текущей строкой в Steam: работающий Steam может ещё не сохранить изменения на диск. ECHO объединит эту строку с командой установленной копии ECHO; скопируйте результат и вставьте его в свойства игры в Steam. Сложные или неоднозначные команды требуют ручной настройки и не изменяются автоматически.

Steam-версия 3.8 сначала запускает официальный лаунчер Kuro. Для уже установленной и обновлённой игры можно экспериментально перенаправить Steam-команду на клиент: в параметрах запуска Steam поместите установленный `echo-native --steam-wrap` перед `%command%`. Если раньше использовался другой инструмент, его нужно сохранить перед ECHO. Например, при пакетной установке и наличии `~/proton-launch`:

```text
~/proton-launch /usr/bin/echo-native --steam-wrap %command%
```

При запуске кнопкой ECHO обёртка ищет клиент и установленный набор качества, сохраняет аргументы Steam/Proton и передаёт нужный `-krqlv`. При обычном запуске из Steam обёртка пропускает команду без изменений, открывая официальный лаунчер. Если клиент или набор качества определить однозначно не удалось, также откроется официальный лаунчер.

## Требования

- Linux x86-64. AppImage рассчитан на совместимые дистрибутивы; DEB — на Debian/Ubuntu с glibc 2.35 или новее.
- Установленная Steam-версия Wuthering Waves (рекомендуется [DWProton](https://github.com/dawn-winery/dwproton-mirror/releases) с фиксом для лаунчера игры).
- Qt 6, SDL3, SQLite и xxhash — зависимости автоматически разрешаются пакетным менеджером.

## Сборка из исходного кода

```bash
cmake -S native -B build/native -DCMAKE_BUILD_TYPE=Release
cmake --build build/native -j3
```

Для создания пакета Arch:

```bash
bash scripts/build-arch-package.sh
```

## Важно

ECHO Native — неофициальное приложение, не связанное с разработчиками Wuthering Waves. Права на игру и сторонние переводы принадлежат их правообладателям. Приложение не включает игровые данные, тексты переводов или оригинальный Windows-лаунчер. Изменение игровых ресурсов может нарушать правила игры и создавать риск блокировки аккаунта.
