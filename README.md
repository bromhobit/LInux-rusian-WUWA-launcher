# ECHO Native

**Лаунчер русской локализации Wuthering Waves для Linux.**

ECHO Native помогает установить, обновить и восстановить текстовый перевод Wuthering Waves в Steam-версии игры. Приложение объединяет управление переводами и запуск игры в одном интерфейсе.

## Возможности

- Выбор локализации: **OVERLINK**, **Aniwie** и **qwikki**.
- Загрузка и установка совместимых переводов с проверкой целостности файлов.
- Проверка версии игры и доступности обновлений перевода.
- Автоматическое обнаружение установки Wuthering Waves в Steam.
- Запуск игры через Steam и управление геймпадом.
- Проверка манифеста при запуске и каждые 30 минут; новые совместимые пакеты загружаются в кеш и проверяются по XXH64.
- Резервное копирование, проверка и восстановление файлов подключения перевода.

## Установка

Для **Arch Linux** и **CachyOS** доступен готовый пакет.

1. Скачайте [пакет echo-native 0.3.0](https://github.com/bromhobit/LInux-rusian-WUWA-launcher/blob/main/release/echo-native-0.3.0-1-x86_64.pkg.tar.zst).
2. Установите пакет:

```bash
sudo pacman -U ./echo-native-0.3.0-1-x86_64.pkg.tar.zst
```

После установки запустите **ECHO Native** из меню приложений.

## Проверка файлов перевода

ECHO ищет Steam-приложение по AppID 3513350 во всех библиотеках Steam, затем определяет папку с клиентом и ресурсами внутри установки. Если найдено несколько подходящих клиентов или несколько версий ресурсов без подтверждения активной версии, установка не выполняется до выяснения пути. Для подключения текста используется штатный `MountResource.txt`, при его отсутствии — `MountLang_en.txt`. Языковые файлы озвучки не заменяются.

Если после обновления игры файл перевода отсутствует, ECHO может предложить установить его повторно. Лаунчер проверяет журнал и таблицу Mount, сохраняет резервную копию журнала и не перезаписывает изменённый или неизвестный файл. Совпадение основной версии и минорной версии игры с переводом не гарантирует совместимость с конкретным микропатчем.

При обнаружении нового совместимого пакета выбранного канала ECHO загружает его в кеш; изменение игровых файлов выполняется после подтверждения установки. При недоступности сети текущие файлы сохраняются. Если обновление игры изменит структуру ресурсов или формат манифеста, может потребоваться обновление ECHO.

## Экспериментальный прямой запуск через Steam

Steam-версия 3.8 сначала запускает официальный лаунчер Kuro. Для уже установленной и обновлённой игры можно экспериментально перенаправить Steam-команду на клиент: в параметрах запуска Steam поместите установленный `echo-native --steam-wrap` перед `%command%`. Если раньше использовался другой инструмент, его нужно сохранить перед ECHO. Например, при пакетной установке и наличии `~/proton-launch`:

```text
~/proton-launch /usr/bin/echo-native --steam-wrap %command%
```

Обёртка сама ищет клиент и установленный набор качества, сохраняет аргументы Steam/Proton и передаёт нужный `-krqlv`. Если выбор клиента или набора неоднозначен, запускается обычный официальный лаунчер. Этот режим пока не проверен в живой игре. Для обновления игры верните обычные параметры запуска или добавьте перед командой `ECHO_OFFICIAL_LAUNCHER=1`.

## Требования

- Linux x86_64 (Arch Linux / CachyOS для готового пакета). На других дистрибутивах соберите приложение из исходников с установленными зависимостями.
- Установленная Steam-версия Wuthering Waves.
- Qt 6, SDL3 и xxhash — зависимости автоматически разрешаются пакетным менеджером.

## Сборка из исходного кода

```bash
cmake -S native -B build/native -DCMAKE_BUILD_TYPE=Release
cmake --build build/native -j3
```

Для создания пакета Arch:

```bash
bash scripts/build-arch-package.sh
```

## Важно

ECHO Native — неофициальное приложение, не связанное с разработчиками Wuthering Waves. Права на игру и сторонние переводы принадлежат их правообладателям. Приложение не включает игровые данные, тексты переводов или оригинальный Windows-лаунчер. Изменение игровых ресурсов может нарушать правила игры и создавать риск блокировки аккаунта.
