# ECHO Native 0.2.1

**Лаунчер русской локализации Wuthering Waves для Linux.**

Приложение позволяет выбирать и устанавливать текстовые переводы, проверять их актуальность, управлять файлами локализации и запускать игру через Steam/Proton.

### Возможности выпуска

- Каналы перевода OVERLINK, Aniwie и qwikki.
- Проверка целостности скачиваемых PAK и контроль совместимости версии игры.
- Резервное копирование и восстановление подключения локализации.
- Обновлённое оформление экрана настроек и единый стиль разделов.
- Готовый установочный пакет для Arch Linux и CachyOS.

### Установка

Скачайте **`echo-native-0.2.1-2-x86_64.pkg.tar.zst`** из вложений выпуска и установите:

```bash
sudo pacman -U ./echo-native-0.2.1-2-x86_64.pkg.tar.zst
```

SHA-256 находится в `SHA256SUMS`.

**Важно:** ECHO Native — неофициальное приложение. Модификация игровых ресурсов может быть обнаружена игрой. Пакет не содержит саму игру или сторонние переводы.
