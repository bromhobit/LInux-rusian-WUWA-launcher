# ECHO Native 0.3.2

Перед запуском через Steam лаунчер проверяет наличие простой исполняемой обёртки в параметрах запуска, когда аккаунт и команда определяются однозначно. Если скрипт отсутствует, приложение показывает понятную ошибку. Сложные параметры запуска остаются под управлением Steam. Исполняемые файлы не восстанавливаются автоматически из корзины.

При запуске Steam очищаются переменные окружения, унаследованные от ярлыка сторонней игры. Сохранены исправления диалогов, управления геймпадом и восстановления перевода из 0.3.1.

## Установка на Arch Linux / CachyOS

Скачайте `echo-native-0.3.2-1-x86_64.pkg.tar.zst` и установите:

```bash
sudo pacman -U ./echo-native-0.3.2-1-x86_64.pkg.tar.zst
```

Контрольные суммы находятся в `SHA256SUMS`. Результат запуска зависит также от настроек Steam, Proton и сторонних инструментов.
