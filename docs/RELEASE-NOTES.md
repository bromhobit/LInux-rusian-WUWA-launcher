# ECHO Native 0.3.0

Улучшено управление геймпадом: видна рамка выбранного элемента, поддерживаются D-pad, стики и диалоги. Отдельный запуск игры без Steam убран из интерфейса; ручная установка файлов перевода и журнал сохранены.

Лаунчер проверяет манифест выбранного перевода, обнаруживает новые совместимые пакеты и загружает их в кеш с проверкой XXH64. Перед изменением файлов игры требуется подтверждение. После обновления игры приложение определяет текущий клиент и таблицу ресурсов, а при неоднозначности останавливает установку.

## Установка на Arch Linux / CachyOS

Скачайте `echo-native-0.3.0-1-x86_64.pkg.tar.zst` и установите:

```bash
sudo pacman -U ./echo-native-0.3.0-1-x86_64.pkg.tar.zst
```

Контрольные суммы находятся в `SHA256SUMS`. Физический геймпад и совместимость с будущими изменениями игры требуют отдельной проверки.
