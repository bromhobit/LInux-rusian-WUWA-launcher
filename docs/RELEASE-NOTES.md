# ECHO Native 0.3.1

Восстановление перевода больше не требует отдельного подтверждения: лаунчер проверяет файлы и сохраняет резервную копию записи ресурсов. После восстановления результат отображается в приложении.

Исправлен контраст диалогов и управление ими с геймпада; стандартные кнопки переведены на русский язык. Ручной выбор файлов использует интерфейс Qt.

## Установка на Arch Linux / CachyOS

Скачайте `echo-native-0.3.1-1-x86_64.pkg.tar.zst` и установите:

```bash
sudo pacman -U ./echo-native-0.3.1-1-x86_64.pkg.tar.zst
```

Контрольные суммы находятся в `SHA256SUMS`. Проверка диалогов выполнена программно; управление физическим геймпадом зависит от настроек системы.
