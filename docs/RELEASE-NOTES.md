# ECHO Native 0.2.3.1

Исправлена повторная установка перевода после обновления игры: если PAK перевода исчез, лаунчер может предложить установить его снова, сохранив прежний журнал установки. Изменённые или неизвестные файлы и конфликтующие записи Mount остаются защищены от перезаписи.

Версия перевода проверяется по основной и минорной версии игры; совместимость с конкретным микропатчем нужно проверять отдельно. Этот выпуск основан на версии 0.2.3 и использует таблицу `MountLang_en.txt`.

### Установка на Arch Linux / CachyOS

Скачайте `echo-native-0.2.3.1-1-x86_64.pkg.tar.zst` и установите:

```bash
sudo pacman -U ./echo-native-0.2.3.1-1-x86_64.pkg.tar.zst
```

Контрольная сумма пакета находится в `SHA256SUMS`. ECHO Native — неофициальное приложение; пакет не содержит игру или переводы.
